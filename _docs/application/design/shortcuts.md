# 画面キーボードショートカット

修飾キーなしの単一キー。入力欄・編集中テキスト上では無効（ポップオーバー内の検索・説明も含む）。**既にモーダルが開いているとき**も無効（入力中の誤発火を防ぐ）。入力欄以外で開いている**ポップオーバーはショートカットを妨げない**。

## 共通（スペース詳細・資料詳細）

| キー | 意味 | 動作 | 対象画面 |
| --- | --- | --- | --- |
| **M** | More | ヘッダー「・・・」（その他）の開閉 | スペース一覧 / ボード / WBS / 資料詳細 |
| **S** | Sidebar | サイドバーの開閉 | ボード / WBS / 資料詳細 |
| **E** | Edit | 編集モードを開始（閲覧 → 編集のみ） | WBS / 資料詳細 |
| **D** | Document | 資料追加モーダルを開く | ボード / WBS / 資料詳細 |

### 補足

- **優先ルール** … 押したショートカットを最優先する。ポップオーバーが開いていても、**N**（作成モーダル）・**D**・**E**・**F**・**M** などは発火する。実行時に開いていたポップオーバーは閉じる。
- **ポップオーバーは画面あたり1つ** … 別のポップオーバー系ショートカットを押すと、開いていた方を閉じて新しい方を開く（`useExclusivePopover`＋各画面の dismiss）。
- **M** … 既に「・・・」が開いていれば閉じる。閉じていれば他を閉じて開く。
- **F** … フィルターの開閉（開いていれば閉じる／閉じていれば他ポップオーバーを閉じて開く）。
- **S** … ページ表示中かつモーダルが無いとき、サイドバーをトグルする。
- **E** … WBS は「WBS編集」、資料詳細は「本文編集」を開始する。すでに編集モード中は何もしない。終了は UI のキャンセル / 保存、または資料本文の Esc。
- **D** / **N** … 対象の作成モーダルを開く（**N** はスペース一覧ではスペース作成、ボードではポインタがリスト列内ならそのリストを初期選択・それ以外と WBS ではヘッダー「タスク追加」と同じ）。既に同種モーダルが開いているときは無効。
- ショートカット付きボタンはホバーで `title`（例: `タスク追加（N）`）を表示する。
- ボードに相当する編集モードはないため、ボードでは **E** は未割り当て。

## 画面別（既存含む）

### スペース一覧

| キー | 動作 |
| --- | --- |
| **N** | スペース作成モーダルを開く |
| **F** | 一覧のフィルター開閉 |
| **M** | ヘッダー「・・・」（その他）の開閉 |

### ボード

| キー | 動作 |
| --- | --- |
| **N** | タスク追加モーダルを開く（リスト列上ならそのリストを初期選択、それ以外はヘッダー「タスク追加」と同じ） |
| **F** | フィルター開閉 |
| **Enter** | ポインタ下のカードのタスク詳細を開く |
| **M** / **S** / **D** | 上記共通どおり |

### WBS

| キー | 動作 |
| --- | --- |
| **N** | タスク追加モーダルを開く（ヘッダー「タスク追加」と同じ） |
| **F** | フィルター開閉 |
| **M** / **S** / **E** / **D** | 上記共通どおり |

### 資料詳細

| キー | 動作 |
| --- | --- |
| **M** / **S** / **E** / **D** | 上記共通どおり |

## 実装メモ

- 共有レジストリは無く、各画面の `document` `keydown` で扱う。
- 入力中判定は `isKeyboardShortcutBlockedTarget`（文字入力欄はポップオーバー内でもショートカットより優先。入力欄以外の浮動ポップオーバーはショートカット優先）、モーダル判定は `getTopmostModalOverlay`（`frontend/app/utils/ui/uiInteraction.ts`）。ポップオーバー開閉はショートカット可否に使わない。
- 主なハンドラ: `WorkspaceBoard.onBoardKeydown` / `WorkspaceDetailView.onProjectViewKeydown` / 資料詳細 `onDocumentPageKeydown` / スペース一覧 `onWorkspaceListKeydown`。
- 対応ボタンのホバー表示は HTML `title`（ブラウザ標準ツールチップ）。
